# 小金毛的家 · 初版（未完成版）

**版本状态：初版 · 未完成版。** 当前用于体验与迭代，角色、动作、音效和玩法仍会继续完善。

本项目为独立的小金毛情绪互动空间；目前为网页原型，还不是微信小程序正式版。

## 打开

在仓库目录启动静态服务：

```powershell
python -m http.server 5174 --bind 127.0.0.1
```

浏览器访问 `http://127.0.0.1:5174/`。入口文件为仓库根目录的 `index.html`。

## 当前功能

- 首次进入的故事信，以及随时重读。
- SVG 卡通房间与真正的 Three.js 立体小金毛：圆脑袋、短胖四肢、软垂耳朵、柔和光照与接触阴影。
- 统一关节角色支持四肢交替、转身、耳朵延迟摆动、起跳蓄力与落地缓冲；动作之间平滑过渡。
- 打滚、疯跑、蹦跳、嗷呜和趴下休息，可切换、重复触发或停止。
- 点击地面左右移动，离开及返回流程。
- 「踢走烦恼」：写一张最多 1000 字的纸条，揉成纸团，由小金毛蓄力踢出打开的窗户，逐渐飞远。支持再写一张、取消编辑和中途停止。
- 纸条文字只存在于当前输入框，关闭或提交即清空，不写入本地存储、不上传，也不复制到动画中。减少动态效果模式提供简化过渡。
- 默认启用音效、音量 85%；首次点击动作后播放，右上角支持 0–100% 音量调节及一键静音，不修改系统音量。
- 原创本地卡通音效：打滚的弹性咕噜声、奔跑的密集脚步、跳跃的弹簧与落地声、夸张嗷呜、休息的小呼噜，以及揉纸、踢纸团、飞远和完成声。动作音效循环，切换、停止、离开和后台切换时清理声音。
- `tools/generate_sounds.py` 使用 Python 标准库生成 WAV；无需外部音效服务。`sound.js` 负责解码缓存、音量控制、淡出与过期播放请求取消。
- 手机布局、键盘按钮操作、减少动态效果偏好支持。
- 不依赖第三方网络资源，不采集情绪；仅在本地保存是否已看过入场故事。

## 当前范围

这是用于确认视觉与互动方向的移动端网页原型，还不是微信小程序安装包。角色由本地 Three.js 0.180.0 程序建模并实时渲染；库与 MIT 许可证保存在 vendor 目录。浏览器不支持 WebGL 时保留原二维角色。后续可在体验确认后进一步细化角色与声音，并迁移到微信小程序。
